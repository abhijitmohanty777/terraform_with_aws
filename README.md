# terraform_with_aws

### 1. Initialize Terraform

```bash
terraform init
```

### 2. Format & Validate Configuration
```bash
terraform fmt        # Automatically format Terraform files
terraform validate   # Validate the configuration syntax
```

### 3. Plan Infrastructure Changes
```bash
terraform plan
```

### 4. Apply Infrastructure
```bash
terraform apply
```

### 5. Destroy Infrastructure
```bash
 terraform destroy
 ```
